### 学习路径：从基础到高阶分析

#### 阶段一：数据筛选与排序（必备基础）

这是你 `SELECT` 之外最先要掌握的，它们是数据探索的基础。

1. **`WHERE` 子句**：按条件筛选数据。
   - **关键**：熟练使用 `AND`, `OR`, `NOT` 逻辑操作符。
   - **关键**：掌握 `BETWEEN`, `LIKE` (用于模糊匹配), `IN`, `IS NULL` / `IS NOT NULL`。
2. **`ORDER BY` 子句**：对结果进行排序（`ASC` 升序, `DESC` 降序）。
3. **`LIMIT` 子句**：限制返回的行数（例如，取 Top 10）。

#### 阶段二：聚合与分组（数据分析的核心）

这是算法岗位的**重中之重**。你需要对数据进行汇总统计。

1. **聚合函数 (Aggregate Functions)**：
   - `COUNT()`: 计数
   - `SUM()`: 求和
   - `AVG()`: 求平均值
   - `MAX()` / `MIN()`: 求最大/最小值
   - `COUNT(DISTINCT col_name)`: 计算不重复值的数量（**非常常用**）
2. **`GROUP BY` 子句**：按一个或多个列对数据进行分组。
   - **核心理念**：将数据“折叠”起来，然后对每个“组”使用聚合函数。
3. **`HAVING` 子句**：
   - **关键**：`WHERE` 是在**分组前**筛选行，`HAVING` 是在**分组后**筛选组。
   - 例如：找出平均客单价（`AVG(price)`）大于100的品类（`GROUP BY category`）。

#### 阶段三：多表连接（处理复杂数据的关键）

真实世界的数据很少只存在一张表里。

1. **`JOIN` 的概念**：理解数据是如何通过“键”(Key)关联起来的。
2. **`INNER JOIN` (内连接)**：最常用的，只保留两张表中都能匹配上的数据。
3. **`LEFT JOIN` (左连接)**：保留左表的所有数据，右表匹配不上的用 `NULL` 填充。（**极其常用**，例如计算用户的订单量，即使某用户没有订单，也保留该用户）。
4. **`UNION` / `UNION ALL`**：
   - `JOIN` 是横向“拼接”列。
   - `UNION` 是纵向“堆叠”行（会去重），`UNION ALL`（不会去重，效率更高）更常用。

#### 阶段四：子查询与CTE（构建复杂逻辑）

这是你区别于初学者的地方，能让你写出更清晰、更复杂的查询。

1. **子查询 (Subquery)**：
   - 嵌套在 `SELECT`, `FROM`, `WHERE` 子句中的查询。
   - 例如：`WHERE user_id IN (SELECT user_id FROM black_list_table)`。
2. **CTE (Common Table Expressions)**：
   - 使用 `WITH ... AS (...)` 语法。
   - **强烈推荐**：这能让你的SQL逻辑极其清晰。你可以把一个复杂的查询拆分成多个命名的、临时的“中间表”，最后再把它们组合起来。对于算法岗位的复杂特征提取，CTEs是必备神器。

#### 阶段五：窗口函数（算法岗的“高阶”分水岭）

**这是你作为算法实习生最需要掌握的高阶技能。** 窗口函数允许你在不“折叠”数据（即不用 `GROUP BY`）的情况下，对数据进行分组计算。

1. **`OVER()` 子句**：窗口函数的标志。
2. **`PARTITION BY`**：在窗口内“分组”。
   - **对比**：`GROUP BY` 会把多行压缩成一行，而 `PARTITION BY` 不会，它只是在计算时“隔开”不同的组。
3. **核心函数**：
   - **排名函数**：`ROW_NUMBER()` (行号), `RANK()` (排名，会跳号), `DENSE_RANK()` (排名，不跳号)。
     - *用途：取每个用户最新的3条订单、每个品类销量前5的商品等。*
   - **分析函数**：`LAG()` / `LEAD()`。
     - *用途：计算用户两次购买之间的时间差、计算日环比/月同比等。*
   - **聚合函数**：`SUM(...) OVER (...)`, `AVG(...) OVER (...)`
     - *用途：计算累计和（Running Total）、计算每个商品占其品类总销量的百分比等。*

### 给你的学习建议

1. **实践为王**：SQL是“手艺活”。找一个在线的SQL练习平台（如 LeetCode, HackerRank, 牛客网）去刷题。
2. **从`GROUP BY`开始**：你目前的基础，请立刻开始学习**阶段二：聚合与分组**。这是你工作中马上就会用到的。
3. **理解`JOIN`**：`LEFT JOIN` 是你构建特征时最常用的。
4. **死磕`Window Function`**：**阶段五：窗口函数** 是你从“会SQL”到“精通SQL（分析）”的真正分水岭。面试算法岗时，这是一个非常大的加分项。
5. **用`CTE`重构**：当你能写出子查询后，尝试用**阶段四：CTE**去重构它，你的SQL会变得更易读、易维护。
